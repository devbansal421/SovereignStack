# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

SovereignStack treats digital sovereignty and supply-chain security with the highest priority.

If you discover a security vulnerability or cross-border exfiltration risk within SovereignStack:

1. **Do not create a public GitHub issue.**
2. Send a detailed report describing the vulnerability, proof of concept, and affected components to the project maintainers.
3. We will acknowledge receipt within 48 hours and provide a timeline for triage and remediation.
